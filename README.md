# Smart-Motion-Detection-and-Alert-System-for-soldiers

## 1. Project Overview

This project presents a Glass-Based Smart Defense and Alert System designed to improve soldier safety through motion detection, silent vibration alerts, image capture and wireless communication.

## 2. Aim

To design and develop a glass-mounted smart defense system that detects nearby movement, alerts the soldier through a vibration motor, captures images using a camera module and transmits alerts wirelessly.

## 3. Abstract

The system uses a PIR sensor to detect motion in the surroundings and a camera module to capture images. A vibrator motor provides silent alerts to the soldier. An Arduino MEGA controls the system, while an ESP32 provides wireless communication to transmit alerts and captured images to a remote monitoring station.

## 4. Components Used

1. Arduino MEGA
2. ESP32
3. PIR Sensor
4. Relay Module
5. Camera Module
6. Vibrator Motor
7. Battery Pack

## 5. Working Principle

- The PIR sensor monitors the surroundings for movement.
- The Arduino MEGA processes the sensor signal.
- The camera module captures an image when motion is detected.
- The vibrator motor provides a silent alert.
- The ESP32 transmits the alert and image wirelessly.

## 6. Applications

- Security monitoring
- Soldier safety systems
- Motion detection
- Remote monitoring

## 7. Advantages

- Hands-free operation.
- Silent vibration alerts.
- Wireless communication.
- Improved response time.
- Portable design.
